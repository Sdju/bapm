# Тесты читают `~/.bapm` пользователя

**Статус:** открыто  
**Класс:** тест

## Суть

Core/CLI тесты не подменяют домашний каталог надёжно. Grant из `~/.bapm/config.json` включает grant-surface и валит посторонние кейсы. В этой сессии файл пришлось переименовать в `config.json.audit-leftover`.

## Состояние

| Источник     | Позиция                                                                                            |
| ------------ | -------------------------------------------------------------------------------------------------- |
| APM          | Свои фикстуры; не относится.                                                                       |
| OpenAPM      | Не регламентирует test harness.                                                                    |
| Спека bapm   | Нет требования изоляции HOME.                                                                      |
| Код bapm     | User store / approve читают `~/.bapm` (или `HOME` процесса). Часть тестов задаёт tmp cwd, не HOME. |
| Документация | Нет.                                                                                               |

## Вариации

1. Каждый тест: `HOME=tmp` + пустой config.
2. Как сейчас: зависит от машины разработчика и агента.
3. Запретить чтение user store в unit-тестах без явного порта.

## Поведение сейчас

`HOME` в среде агента был `/tmp/v3/home`. Реальный `~/.bapm` всё равно читался частью suite. Семь падений core после ручного `approve` — не регрессия продукта, а загрязнение store. Тесты нельзя считать изолированными.
