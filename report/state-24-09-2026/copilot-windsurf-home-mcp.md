# Copilot и Windsurf пишут MCP в `$HOME`

**Статус:** намеренно  
**Класс:** продукт

## Суть

Остальные агенты держат MCP в проекте. Copilot пишет `~/.copilot/mcp-config.json`, Windsurf — `~/.codeium/windsurf/mcp_config.json`. Настройки общие на все репозитории машины.

## Состояние

| Источник     | Позиция                                                           |
| ------------ | ----------------------------------------------------------------- |
| APM          | Те же хосты часто используют user-global MCP.                     |
| OpenAPM      | Deploy roots MAY быть вне проекта, если так зарегистрирован хост. |
| Спека bapm   | Path может быть `~/…`; install принимает tilde.                   |
| Код bapm     | `integration-copilot`, `integration-windsurf`.                    |
| Документация | `guide/supported-hosts.md`: явное предупреждение.                 |

## Вариации

1. Писать проектный MCP, если хост умеет (Copilot project mcp — отдельный формат, не используется).
2. User-global (текущее).
3. Не деплоить MCP этим хостам без отдельного флага.

## Поведение сейчас

Два проекта с разными GitHub MCP на одной машине перезапишут один и тот же user-файл. Это не bug относительно интеграций, но ломает ожидание «install проекта локален».
