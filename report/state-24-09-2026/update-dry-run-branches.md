# `update --dry-run` показывает ветки как `keep`

**Статус:** открыто  
**Класс:** продукт

## Суть

План `--dry-run` смотрит semver-constraint / выведенный `^major` из тега. У пакета на ветке (`#main`) constraint нет — в плане `keep`. `update -y` затем резолвит git заново и сдвигает коммит.

## Состояние

| Источник     | Позиция                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| APM          | `outdated` показывает drift ветки; plan update может отличаться от apply.                                                       |
| OpenAPM      | Mutable ref vs pinned commit — разные операции.                                                                                 |
| Спека bapm   | Update plan vs apply; outdated сравнивает tip ветки.                                                                            |
| Код bapm     | `runUpdate.ts`: без `constraint` / выведенного диапазона — `action: "keep"`. Apply идёт через `resolveAndLock` и двигает ветки. |
| Документация | `guide/situations/update-deps.md`: «пакеты на ветках помечены `keep`, хотя `update -y` их сдвинет».                             |

## Вариации

1. Dry-run резолвит ветки так же, как apply.
2. Dry-run только semver (текущее) — план врёт про ветки.
3. Печатать отдельную строку «branch: unknown until apply».

## Поведение сейчас

Полная картина — `bapm outdated`. `--dry-run` без `-v` ещё и прячет строки `keep`, поэтому ветки могут не попасть в вывод вовсе.
