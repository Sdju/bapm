# Неподдерживаемые типы файлов пропускаются без сообщения

**Статус:** намеренно  
**Класс:** продукт

## Суть

Если пакет принёс hooks, а хост их не умеет, install не пишет warning. Пользователь видит «installed for opencode» и думает, что hooks на месте.

## Состояние

| Источник     | Позиция                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| APM          | Часть адаптеров логирует skip.                                                                                       |
| OpenAPM      | Неподдерживаемый primitive MAY быть пропущен; MUST ли говорить — не жёстко.                                          |
| Спека bapm   | Host materialize пропускает неизвестные типы.                                                                        |
| Код bapm     | Интеграции фильтруют по поддерживаемым kinds без diagnostics. OpenCode дополнительно молча пропускает `sse` и hooks. |
| Документация | `guide/supported-hosts.md` таблица `#skipped`.                                                                       |

## Вариации

1. Печатать `skipped hooks for opencode`.
2. Тихий skip (текущее).
3. Fail-closed, если пакет декларирует только неподдерживаемые типы.

## Поведение сейчас

Таблица пропусков — в docs, не в выводе CLI. Codex не кладёт commands, Windsurf — agents, Grok — hooks и commands, agent-skills — всё кроме skills.
