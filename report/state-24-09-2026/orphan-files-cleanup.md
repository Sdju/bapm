# Сироты после удаления пакета из манифеста

**Статус:** открыто (docs и код расходятся в нюансе)  
**Класс:** баг / продукт

## Суть

Пользователь ждёт: убрал пакет из `bapm.yml`, сделал `install` — файлы агента исчезли. Так бывает только если в предыдущем lock были `deployed_file_hashes`. Пустые каталоги и файлы вне инвентаря остаются. Frozen install сирот не чистит.

## Состояние

| Источник     | Позиция                                                                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APM          | Повторный install/uninstall опирается на inventory в lock.                                                                                                                               |
| OpenAPM      | lk-017: сверка развёрнутых файлов с хешами; orphan cleanup — производное.                                                                                                                |
| Спека bapm   | Install чистит harness-файлы пакетов, которых больше нет в resolve set.                                                                                                                  |
| Код bapm     | `cleanupOrphanDeployedFiles` вызывается из install, если не frozen. Удаляет только пути из `deployed_file_hashes` пропавших deps. Ошибки unlink глотаются. Пустые родители не удаляются. |
| Документация | `reference/install.md`: «если пакет убран из манифеста вручную, файлы не удаляются» — жёстче, чем код.                                                                                   |

## Вариации

1. Всегда чистить по inventory (код, незамороженный install).
2. Никогда не чистить на install, только `uninstall`/`prune` (текст docs).
3. Чистить и пустые каталоги, и файлы без хешей — сейчас нет.

## Поведение сейчас

Не frozen `install` удалит файлы, которые предыдущий lock приписал снятому пакету. Нет хешей — нет удаления. Frozen (в том числе CI-default) этот шаг пропускает. `uninstall` зовёт ту же функцию после правки lock.
