# `--force` у install ничего не делает

**Статус:** открыто  
**Класс:** баг / незавершённый флаг

## Суть

Флаг есть в CLI и в спеке «для паритета с APM», но ядро его игнорирует. Пользователь, который знает APM, ожидает обход коллизий или обновление refs.

## Состояние

| Источник     | Позиция                                                                                                                                                                                                                     |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APM          | `--force` меняет ход установки (как минимум коллизии / refresh в привычном UX APM).                                                                                                                                         |
| OpenAPM      | Отдельного обязательного `--force` нет.                                                                                                                                                                                     |
| Спека bapm   | `install-pipeline`: force MUST NOT обновлять refs, MUST NOT обходить frozen и policy. Одновременно: «accepted for CLI parity and any future thin security-gate bypass». `cli-runtime-surface` требует документировать флаг. |
| Код bapm     | `runInstall.ts`: `void options.force;` — значение отбрасывается.                                                                                                                                                            |
| Документация | `reference/install.md` и help: «сейчас без эффекта».                                                                                                                                                                        |

## Вариации

1. Оставить no-op навсегда и убрать флаг — ломает скрипты, которые уже передают `--force`.
2. Оставить приём флага без эффекта (текущее) — сюрприз для тех, кто шёл из APM.
3. Дать узкий смысл: например, разрешить перезапись при zip-merge или refresh refs. Спека прямо запрещает refresh и обход frozen/policy.

## Поведение сейчас

`bapm install --force` парсится, неизвестным флагом не считается и не меняет ни refs, ни frozen, ни policy, ни перезапись файлов. Не путать с `--target` (forced target).
