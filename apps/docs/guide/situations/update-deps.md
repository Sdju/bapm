# Обновить зависимости

## Ситуация

В манифесте указаны ветки (`acme/skills`, `#main`) или диапазоны версий, а lock закрепил коммиты на момент первой установки. Вышли новые версии, и вы хотите их получить.

Пока lock не обновлён, `bapm install` продолжит ставить закреплённые коммиты: так команда получает одинаковые версии.

## Шаги

### 1. Посмотрите, что устарело

```bash
bapm outdated
```

Команда ничего не меняет. Для скриптов: `bapm outdated --json`.

### 2. Посмотрите план

```bash
bapm update --dry-run
```

План показывает только изменения по semver-диапазонам. Пакеты на ветках там помечены `keep`, хотя `update -y` их сдвинет на свежий коммит. Полную картину даёт `bapm outdated` из шага 1.

### 3. Обновите

```bash
bapm update -y                 # все пакеты
bapm update -y acme/skills     # только выбранные
```

Без `-y` в терминале `update` спросит `Apply? [y/N]`. В CI и скриптах без `-y` обновление не применится.

### 4. Разложите файлы и закоммитьте

```bash
bapm install
git add bapm.lock.yaml
```

`bapm install --update` делает шаги 3 и 4 за один раз, но без предварительного плана.

## Как понять, что обновлять

| Что в манифесте    | С чем сравнивает `outdated`                  |
| ------------------ | -------------------------------------------- |
| ветка или тег      | последний коммит этой ветки или тега         |
| диапазон `^1.0.0`  | старший подходящий semver-тег                |
| полный хеш коммита | последний semver-тег (только для информации) |

Пакет, закреплённый на полном хеше коммита, `update` не сдвинет. Чтобы обновить его, поменяйте ref в `bapm.yml`, выполните `bapm install` и проверьте, что коммит в `bapm.lock.yaml` сменился.

## Если не получилось

| Проблема                                                | Что делать                                                             |
| ------------------------------------------------------- | ---------------------------------------------------------------------- |
| `update` в CI ничего не применил                        | Добавьте `-y`                                                          |
| `outdated` падает                                       | Нет lock: сначала `bapm install`                                       |
| `--update` запрещён вместе с frozen                     | В CI install работает как frozen. Обновляйте локально и коммитьте lock |
| `--dry-run` показал `keep`, а `update -y` сдвинул пакет | Пакет на ветке: план этого не показывает. Сверяйтесь с `bapm outdated` |
