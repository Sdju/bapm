## Перед началом

- CLI и host-интеграции ставятся отдельно. Для известного host object-map `targets:` не нужен: достаточно подходящего `@b-apm/integration-<id>`.
- `bapm install` выбирает host через `--target`, затем `active`, затем один однозначно обнаруженный маркер. При неоднозначности команда останавливается и просит явный выбор.
- Отдельные hosts поддерживают разный набор артефактов. Неподдерживаемый примитив пропускается с диагностикой; он не преобразуется в другой тип автоматически.
