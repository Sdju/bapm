# bapm uninstall — флаги

По `bapm uninstall --help`.

## Использование

```text
bapm uninstall <packages...> [--dry-run]
```

Убирает пакеты из манифеста, modules, deploy и lock. Positionals обязательны для полезного запуска (имена пакетов). Неизвестные флаги отвергаются.

## Параметры

| Флаг           | Значение | Эффект             | Default |
| -------------- | -------- | ------------------ | ------- |
| `--dry-run`    | —        | Превью без мутаций | off     |
| `--help`, `-h` | —        | Показать help      | —       |

## Сопоставление имён

Пакет ищется по точной идентичности: имя пакета (`name`), alias или `id` из манифеста, полный git URL, короткое имя / последний сегмент URL (без `.git` и завершающих `/`), basename пути `path:`/`local`, а также `name`/`repo_url` из lock. Совпадение по подстроке не используется: `bapm uninstall foo` не заденет `foo-bar`.

Если пакет объявлен как `path: ./pkgdir`, а его манифестное имя — `@acme/tool`, сработают оба варианта: `bapm uninstall @acme/tool` и `bapm uninstall pkgdir`.

Для git-пакетов запись удаляется и из манифеста, и из lock, а развёрнутые файлы и каталог модулей очищаются. Если точное имя совпадает с несколькими пакетами (например, одинаковый basename у разных источников), проверьте план через `--dry-run`.

См. также: [prune](/reference/prune), [install](/reference/install).
