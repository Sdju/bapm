# bapm uninstall — флаги

По `bapm uninstall --help`.

## Использование

```text
bapm uninstall <packages...> [--dry-run]
```

Убирает пакеты из манифеста, modules, deploy и lock. Positionals обязательны для полезного запуска (имена пакетов). Неизвестные флаги отвергаются.

## Параметры

| Флаг           | Значение | Эффект             | Default |
| -------------- | -------- | ------------------ | ------- |
| `--dry-run`    | —        | Превью без мутаций | off     |
| `--help`, `-h` | —        | Показать help      | —       |

::: warning Ограничения текущей версии
`uninstall` работает не так, как описано в help:

- **git-пакеты**: по имени пакета (`name` из его манифеста или последний сегмент URL) команда убирает его из lock и удаляет развёрнутые файлы, но запись в `bapm.yml` остаётся, и следующий `install` вернёт пакет. Каталог в `apm_modules/` тоже остаётся. Полный URL из манифеста не распознаётся.
- **`path:` и `local`**: команда завершается успешно, но ничего не удаляет.
- Имя сравнивается по вхождению подстроки, поэтому короткое имя может задеть несколько пакетов. Проверяйте через `--dry-run`.

Надёжный путь для любого пакета: удалите запись из `bapm.yml`, выполните `bapm uninstall <имя>` (для git-пакетов) или удалите развёрнутые файлы вручную, затем `bapm prune`.
:::

См. также: [prune](/reference/prune), [install](/reference/install).
